# .github

Organisation-level defaults for **[CognitionSync](https://cognitionsync.com)**.

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | Rendered on the [organisation page](https://github.com/cognitionsync) |
| [`profile/assets/`](profile/assets/) | Brand assets used by that page |

Editing `profile/README.md` changes what visitors see at
[github.com/cognitionsync](https://github.com/cognitionsync).

Banner images are animated SVGs with light and dark variants, selected via
`<picture>` and `prefers-color-scheme`. PNG equivalents sit beside them for use
anywhere SVG is not accepted. Brand rules and regeneration steps live in
`BRAND.md` in the main project repo.
